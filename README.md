# 🎲 Бот «Твистед дня» для Dandy's World

Каждый день после смены Daily Twisted Board (00:00 UTC = 03:00 МСК) бот присылает в Telegram,
какой твистед сейчас на доске. Данные берутся с фанатской вики
(dandys-world-robloxhorror.fandom.com), запускается бесплатно через GitHub Actions —
свой сервер и включённый компьютер не нужны.

## Как это работает

- С 00:15 до 06:15 UTC GitHub раз в час запускает `bot.py`.
- Бот смотрит на вики, кто сейчас на доске, и отправляет сообщение.
- Вики обновляют люди вручную. Если там всё ещё вчерашний твистед, бот ждёт следующего запуска.
  После 06:00 UTC отправляет как есть (твистед может и правда повториться).
- В `state.json` бот записывает, что уже отправил сегодня, чтобы не слать дважды.

## Настройка (≈10 минут)

### 1. Создай бота в Telegram
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username.
2. Скопируй **токен** (вида `123456789:AAH...`). Никому его не показывай.

### 2. Реши, куда слать сообщения
- **В канал:** добавь бота в канал **администратором** с правом публиковать сообщения.
  Chat ID будет `@имя_канала` (например `@my_dandy_channel`).
  Для приватного канала нужен числовой id вида `-100...` — его можно узнать,
  переслав пост из канала боту [@userinfobot](https://t.me/userinfobot) или похожему.
- **Себе в личку:** напиши своему боту `/start`, потом узнай свой id у
  [@userinfobot](https://t.me/userinfobot). Это и есть Chat ID.

### 3. Залей код на GitHub
1. Зарегистрируйся на [github.com](https://github.com) и создай новый репозиторий
   (**New repository**, можно публичный — тогда Actions полностью бесплатны).
2. Загрузи файлы: **Add file → Upload files** → `bot.py` и `README.md`.
3. Файл расписания должен лежать по пути `.github/workflows/daily-twisted.yml`.
   Проще всего: **Add file → Create new file**, в поле имени напечатай
   `.github/workflows/daily-twisted.yml` (папки создадутся сами из-за `/`),
   вставь содержимое файла и нажми **Commit changes**.

### 4. Добавь секреты
В репозитории: **Settings → Secrets and variables → Actions → New repository secret**
- `TELEGRAM_BOT_TOKEN` — токен из шага 1
- `TELEGRAM_CHAT_ID` — `@имя_канала` или числовой id из шага 2

### 5. Проверь
Вкладка **Actions** → слева **Twisted of the Day** → **Run workflow** →
поставь галочку «Отправить сообщение, даже если сегодня уже отправляли» → **Run workflow**.
Через полминуты сообщение должно прийти. Дальше всё будет работать само.

> Если Actions не запускаются, проверь **Settings → Actions → General**:
> должно быть разрешено запускать workflows и стоять **Read and write permissions**.

## Настройки

В `.github/workflows/daily-twisted.yml` в блок `env:` можно добавить:
- `LOCAL_TZ: Europe/Kyiv` и `LOCAL_TZ_LABEL: Киев` — другой часовой пояс в сообщении
  (по умолчанию Москва).

Текст сообщения меняется в функции `build_message` в `bot.py`.

## Проверка у себя на компьютере

```bash
python bot.py --dry-run     # показать сообщение, ничего не отправлять
```

## Если что-то сломалось

- **Run завершился красным, «Не получилось узнать твистеда дня»** — вики поменяла
  оформление. Посмотри, что написано на главной странице вики, и поправь `extract_twisted`
  в `bot.py`. GitHub пришлёт письмо о неудачном запуске.
- **«Telegram ответил ошибкой 400: chat not found»** — неверный Chat ID или бот не добавлен в канал.
- **«403: bot is not a member» / «not enough rights»** — сделай бота админом канала.
- **Сообщение пришло поздно** — GitHub иногда запускает расписание с задержкой
  до получаса, это нормально.
